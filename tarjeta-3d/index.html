Demo — recreación en HTML del 3d-card de Aceternity UI; no modifica Mi Biblioteca.

Diferencias respecto a la fuente

  • Sin React, Next, Tailwind ni shadcn (no hay components.json aquí): todo es HTML, CSS y JavaScript plano en un solo archivo.
  • cn es una función pequeña de unir clases, no la utilidad de clsx + tailwind-merge.
  • La imagen de Unsplash de la fuente se sustituye por una dona SVG dibujada a mano con datos reales (NS 89,9 %, meta 90 %).
  • El componente es una página autocontenida, no un import: cero dependencias externas y cero requests externos (el enlace a Tableau solo se abre al hacer clic).
  • Se añade un interruptor claro/oscuro (la fuente usa las clases dark: de Tailwind) y se respeta prefers-reduced-motion: con movimiento reducido la tarjeta queda estática con los datos visibles.
